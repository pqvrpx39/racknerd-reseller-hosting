## 分销主机是什么，和 VPS、虚拟主机差在哪

分销主机是拿来“转卖”的主机。你从 RackNerd 批发一批带资源限额的 cPanel 子账户，拿到 WHM（Web Host Manager）管理后台，在总额度内自由切分套餐、自定义价格、创建客户账户——对客户来说，你就是一家独立的主机商。

三者的分工可以这样理解：虚拟主机是分好自用的，适合个人建一两个站；VPS 给你完整的 root 权限，想装什么装什么，但系统运维要自己扛，而且 cPanel 授权按账户数单独收费，成本不低；分销主机把 WHM、cPanel 和计费系统打包进套餐价，你只管卖。

这套模式适合两类人：手里有一批建站客户的外包工作室，想顺手把托管服务做了；以及想低成本试水主机生意、又完全没有运维经验的新手。反过来，客户量已经做到几十上百个、或者要跑视频站、高并发电商的，分销主线封顶 60 个 cPanel 账户，到顶之后该看的是 VPS 或独立服务器。

## 下单到开通：六步流程和三个易错点

全流程线上完成，付款后通常几分钟到 15 分钟内开通。步骤本身不难，容易出问题的是几个细节。

1. 选好套餐进入下单页，处理域名：注册新域名、从别处转入，或直接使用已有域名
2. 配置订单：确认计费周期和机房位置（选新加坡会自动加价）
3. 结账：支持 PayPal、信用卡、加密货币和银行电汇，首次购买需要填写账单信息创建账户
4. 等激活邮件，用邮件里的凭据登录 RackNerd 客户中心
5. 在客户中心的 Services 里找到分销主机服务，登录 WHM，开始创建套餐、分配资源
6. 登录客户中心提交工单（选 Support 部门），申请免费 ClientExec 授权

三个易错点：

- **ClientExec 要主动申请**。授权不会自动发放，需要提交工单领取。漏了这步的新手，前期只能手动记账开票。
- **已注册的域名不能重复使用**。如果你之前在 RackNerd 注册过某个域名，同一域名无法用于新订单，换个名字或后缀即可。
- **限时促销基本只通过邮件通知**。下单时勾选订阅邮件列表，后面能省不少钱。
